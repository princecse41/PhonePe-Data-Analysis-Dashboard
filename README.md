# PhonePe-Data-Analysis-Dashboard

## 📊 Project Overview

This project is an interactive **PhonePe Data Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes transaction data to understand transaction performance, payment status, transaction amounts, user activity, services, service types, and monthly transaction trends.

The main objective of this project is to transform raw transaction data into meaningful business insights through interactive data visualization and DAX-based analysis.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze the overall transaction performance.
- Track total transaction volume and transaction amount.
- Analyze successful and failed transactions.
- Understand transaction distribution across different services.
- Analyze different service types.
- Identify monthly transaction trends.
- Analyze the number of users.
- Understand payment status distribution.
- Create an interactive and user-friendly Power BI dashboard.
- Generate meaningful business insights from transaction data.

---
